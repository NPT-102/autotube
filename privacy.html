Privacy Policy

AutoTube Studio · Last updated: October 27, 2026

AutoTube Studio is a private tool that runs on its owner's own computer and uploads the owner's own videos to the owner's own YouTube channels. This policy explains what data it accesses and how that data is handled.

YouTube API Services

AutoTube Studio uses YouTube API Services. By connecting a YouTube channel to it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What data is accessed

When the channel owner signs in with Google and grants permission, AutoTube Studio receives an access token for that YouTube channel. It uses this access only to:

  • upload videos made by the owner, and set their title, description, tags, privacy and publish time;
  • set each video's thumbnail and upload its captions;
  • add videos to the owner's playlists;
  • read the channel's name, ID, picture and subscriber count, to show which channel is connected;
  • read the names of the channel's playlists, so the owner can choose one;
  • read the titles and dates of the channel's 10 most recent uploads, only to avoid uploading the same video twice, and read the processing status of a video it has just uploaded.

Apart from these checks, it does not read the channel's videos, comments, messages, viewers or analytics, and it never accesses any channel other than the ones its owner connects. Nothing it reads is kept beyond the moment it is used.

How the data is stored

  • The access token and the channel's name and ID are stored only on the owner's computer, in the tool's own data folder.
  • Nothing is sent to any server other than Google's own YouTube API.
  • The tool has no user accounts, uses no cookies and no analytics, and shows no advertising.

Sharing

No data obtained through the YouTube API is sold, shared with or disclosed to any third party.

Revoking access and deleting data

  • Choosing "Disconnect" for a channel inside AutoTube Studio deletes its stored token from the computer.
  • Access can also be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions.
  • Any stored data can be deleted on request by writing to the contact address below.
