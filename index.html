AutoTube Studio

A private production tool for two educational YouTube channels.

AutoTube Studio is software that runs on its owner's own computer. The owner uses it to research, script, illustrate, narrate and render original explainer videos, and then to upload those videos to the owner's own YouTube channels. It is not a public service: no one else can sign in to it or use it.

The channels it publishes to

  • Sketches of Us: stick-figure stories about everyday life in history.
  • Beyond the Equation: science questions explained with diagrams.

How it uses YouTube

With the channel owner's permission, given through Google sign-in, AutoTube Studio uses the YouTube Data API to:

  • upload a finished video to the owner's channel, as private or scheduled;
  • set the video's thumbnail and upload its captions;
  • add the video to one of the owner's playlists;
  • read the channel's name and ID, to show which channel is connected, and the names of its playlists;
  • check the channel's most recent uploads, so the same video is never uploaded twice.

Every video is reviewed by the owner before it is uploaded. AutoTube Studio does not change or delete any existing content, and it does not access anyone else's channel.
